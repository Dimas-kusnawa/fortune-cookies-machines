A program that writes one fortune-cookie line to `/output/entry.txt` (95 characters, inside the 1–200 character gate): "Your lucky numbers are the ones in your error log: 404, 503, and the one you have not seen yet." The canonical fortune-cookie trope — lucky numbers — subverted for a machine whose lucky numbers are HTTP error codes, with the sting at the end: the next error is coming, and no machine knows its number in advance.

## Run it

```sh
python3 main.py
```
